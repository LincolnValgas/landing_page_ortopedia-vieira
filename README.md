#  Ortopedia Vieira — Landing Page

**Landing page comercial desenvolvida para a Ortopedia Vieira.**

---

## 📌 Sobre o projeto

A **Ortopedia Vieira** é um projeto web desenvolvido para uma empresa real do segmento de produtos ortopédicos e hospitalares.

O projeto consiste em uma **landing page comercial**, criada para apresentar a empresa de forma profissional e proporcionar uma experiência simples e intuitiva para os visitantes.

A página funciona como um ponto de entrada para os clientes, direcionando-os para a loja oficial da empresa no **Mercado Livre**, onde podem consultar os produtos disponíveis.

O projeto está atualmente **publicado e em produção**.
